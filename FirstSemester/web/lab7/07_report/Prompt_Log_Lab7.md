## 1. Master Prompt (Глобальний системний промпт для генерації базового каркасу лендингу)
> **Контекст та інженерна формула:** Роль $\rightarrow$ Тематика $\rightarrow$ Структура $\rightarrow$ Стилістика $\rightarrow$ Обмеження  
> **Промпт:**  
> "Ти — Senior Frontend Developer та UI/UX Engineer.  
> Створи повноцінний адаптивний Landing Page для українського вебпроєкту «ChargeUA» (веб-помічник та агрегатор швидкісних зарядних станцій електромобілів в Україні).  
> 
> Специфікація та бізнес-правило:  
> ChargeUA є безкоштовним інформаційним довідником і агрегатором станцій (пошук та моніторинг живих статусів у блекаути). Жодних фінансових транзакцій, оплат, кошиків чи бронювання конекторів.  
> 
> Структура лендингу згідно з методичкою:  
> 1. Шапка (Header) — логотип ChargeUA, навігація (десктоп горизонтальна, на мобільних бургер), кнопка швидкого пошуку найближчої станції.  
> 2. Головний екран (Hero-секція) — заголовок H1, підзаголовок з ціннісною пропозицією, чітка кнопка CTA («Знайти зарядку»), бейджи швидких переваг (150 кВт, 24/7).  
> 3. Переваги (Benefits) — картки ключових переваг: моніторинг енергопостачання та генераторів, живі статуси портів CCS2/CHAdeMO/GBT, точні тарифи.  
> 4. Каталог станцій (Services / Hubs) — адаптивна сітка карток міських зарядних комплексів (Київ, Львів, Одеса) з живими статусами портів («Вільний» / «Зайнятий»).  
> 5. Відгуки (Testimonials) — соціальні докази та цитати реальних власників електрокарів.  
> 6. Фінальний CTA-блок — конверсійний блок заклику скористатися картою та знайти вільний порт.  
> 7. Підвал (Footer) — семантичний футер: навігація, служба цілодобової підтримки, копірайт.  
> 
> Технічні вимоги:  
> - Семантичний HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).  
> - Стилізація виключно через Tailwind CSS (utility-first) за принципом Mobile-First.  
> - Палітра: Primary Blue (#2563EB / bg-blue-600), Dark Slate (#0F172A / bg-slate-900), Neutral Slate (#F8FAFC / bg-slate-50).  
> - Доступність (a11y): контрастність кольорів, атрибути aria-label для кнопок, правильна ієрархія заголовків H1-H3.  
> - Повністю адаптивний каркас (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`).  
> 
> Згенеруй чистий, валідний HTML-код сторінки та коротко опиши застосовані інженерні рішення."
