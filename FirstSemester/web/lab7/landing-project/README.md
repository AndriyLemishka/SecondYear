# Лабораторна робота №7: Проєктування та реалізація повноцінного лендингу
## Інтеграція інтерактивної карти ChargeUA

Цей проєкт містить повну реалізацію сучасного лендингу сервісу **ChargeUA** відповідно до макета Figma (ЛР №4) та вимог **Лабораторної роботи №7**.

### Ключові компоненти, реалізовані для ЛР №7:
1. **Інтеграція інтерактивної карти**:
   - Інтегровано відкриту картографічну бібліотеку **Leaflet JS** та шари **OpenStreetMap (CARTO Voyager)**.
   - Розроблено кластеризовані маркери зарядних хабів з індикаторами потужності (DC 160 кВт Ultra-fast, Type 2, CHAdeMO).
   - Інтерактивні модальні попапи станцій із відображенням статусу в реальному часі («Вільний», «Зайнятий»), кількості вільних портів, вартості за 1 кВт·год та адреси.
2. **Фільтрація та перемикання локацій**:
   - Швидкі фільтри міст: Львів, Київ, Одеса, Дніпро, траси, вся Україна.
   - Фільтрація за типами конекторів (CCS 2, CHAdeMO, GB/T, Type 2) та автономністю (наявність резервного генератора).
3. **Повноцінна структура лендингу**:
   - Hero-блок із закликом до дії (CTA), смуга переваг (Strip), каталог станцій (CSS Grid), секція розрахунку вартості, блок відгуків та підвал сайту з мікророзміткою.
