# Лабораторна робота №10: Інтеграція динамічних медіакомпонентів та JS-бібліотек
## Медіа-архітектура та плагіни ChargeUA

Цей проєкт демонструє реалізацію вимог **Лабораторної роботи №10**: підключення зовнішніх JavaScript-бібліотек, інтеграцію динамічних фонових медіапотоків та оптимізацію відтворення.

### Реалізовані компоненти для ЛР №10:
1. **Динамічний Hero Video Background**:
   - Апаратне безшовне відеовідтворення (`<video autoplay loop muted playsinline poster="assets/images/hero_loop_opt.gif">`).
   - Підтримка формату MP4 H.264 (`assets/video/video_content.mp4`) з автоматичним fall-back на оптимізований GIF (`assets/images/hero_loop_opt.gif`) для енергозберігаючих пристроїв.
   - Медіа-індикатор зі статусом активного стрімінгу (`.hero-video-badge`).
   - Напівпрозорий градієнтний оверлей (`.hero-fade-overlay`) для збереження високої контрастності типографіки (WCAG 2.2 AA).
2. **Підключення та ініціалізація зовнішніх JS-плагінів**:
   - Інтеграція бібліотеки Leaflet JS через CDN із перевіркою цілісності хешу `integrity`.
   - Архітектурна ізоляція скриптів (`js/map.js`, `js/nav.js`) з відкладеним завантаженням (`defer`).
