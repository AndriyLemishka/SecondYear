Розуміння філософії сучасної верстки: чим відрізняється справжній семантичний код від застарілої div-мішанини.

Проблема «Div Soup»

Коли сайт побудований виключно на <div>, браузер та пошуковий робот бачать суцільне беззмістовне полотно. div не має власного значення — це просто невидима коробочка. Екранні диктори не можуть пояснити незрячому користувачу, де шапка, де навігація, а де головний текст.

Чому заборонено: руйнує SEO та доступність
🌳

Accessibility Tree

Поруч із DOM-деревом браузер формує Accessibility Tree (Дерево доступності). Семантичні теги автоматично надають елементам стандартні ролі: <header> отримує роль banner, <nav> — navigation, <main> — main, а <footer> — contentinfo.

Золоте правило <h1>

На всій сторінці повинен бути рівно один тег <h1>! Він позначає глобальну тему документа (для нас: «Швидка та надійна зарядка електромобілів по всій Україні»). Усі секції позначаються <h2>, а картки станцій чи послуг всередині них — <h3>. Не можна пропускати рівні!

Ієрархія: h1 → h2 → h3
Тег Семантична роль Чи обов'язковий заголовок? Коли обирати (Приклад у ChargeUA)
<article> Самодостатній незалежний блок, що має сенс окремо від сторінки Так (h3 або h4) Картка зарядної станції (DC 150 кВт), пост блогу, відгук користувача
<section> Тематичний розділ сторінки, що групує пов'язаний контент Обов'язково (h2) Секція каталогу станцій, секція інтерактивної карти, секція переваг

<div> Ніякої (чисто технічна обгортка для CSS/стилізації) Ні Контейнер .container для обмеження 1200px, .grid

⚖️ Залізне правило вибору: <button> чи <a>?

Це улюблене підступне питання викладачів на захисті! Запам'ятайте раз і назавжди:

  • Тег <a href="..."> (Посилання): використовується виключно тоді, коли користувач кудись переходить (зміна URL, відкриття іншої сторінки, перехід до якірного блоку #stations або дзвінок tel:).
  • Тег <button type="button"> (Кнопка): використовується, коли користувач виконує дію на поточній сторінці без зміни URL (відкрити модальне вікно, змінити фільтр, розрахувати вартість заряду в калькуляторі, відправити форму type="submit").

CSS Архітектура: Як це працює під капотом

Дворівнева блочна модель: чому макет побудовано на симбіозі CSS Grid та Flexbox, і як влаштовані токени в :root.

➡️

CSS Flexbox (Одновимірний 1D макет)

Flexbox призначений для розміщення елементів в одному напрямку (або в рядок, або в колонку).

  • Головна вісь (Main Axis): керується justify-content (flex-start, space-between, center).
  • Поперечна вісь (Cross Axis): керується align-items (center, stretch).
  • Де використано у нас:
    • Шапка .header-inner: логотип зліва, меню в центрі, CTA справа (justify-content: space-between).
    • Навігація .nav-list: горизонтальний ланцюжок посилань з gap: var(--space-5).
    • Картка .card: вертикальний Flexbox з притисканням кнопки дії донизу (flex-direction: column).
▦

CSS Grid (Двовимірний 2D макет)

CSS Grid керує і рядками, і стовпчиками одночасно, створюючи каркасну матрицю сторінки.

css/style.css — Сітка каталогу 
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: var(--space-6);
}

Розбір магічної формули:
• repeat() — генерує колони без ручного повторення.
• auto-fit — створює стільки колонок, скільки влізе, і розтягує наявні на всю ширину (collapse empty tracks).
• minmax(280px, 1fr) — кожна картка не менше 280px, а вільне місце ділиться порівну.
• gap — ідеальні відступи між картками без жодних margin-left/right.

🎨 Токени дизайн-системи у псевдокласі :root

Чому ми використовуємо :root? Це псевдоклас, що вказує на кореневий елемент <html>, але має вищу специфічність. Оголошені там змінні стають глобальними та каскадуються по всьому дереву документа.

css/style.css — Токени бренду ChargeUA 
:root {
  /* 1. Кольори за призначенням (role-based) */
  --color-primary: #005EC9;       /* Основний акцент бренду ChargeUA */
  --color-secondary: #0F172A;     /* Глибокий контрастний темний фон */
  --color-accent: #00B4D8;        /* Бірюзовий статус швидкої DC зарядки */
  --color-bg: #FFFFFF;            /* Світлий базовий фон сторінки */
  --color-surface: #F8FAFC;       /* Фоновий колір карточок */
  --color-text: #1E293B;          /* Текст із контрастом > 7:1 */

  /* 2. Статуси станцій (WCAG 1.4.1 колір + текст) */
  --color-status-free: #10B981;   /* Зелений: порт вільний */
  --color-status-busy: #EF4444;   /* Червоний: зайнятий */
  --color-status-reserved: #F59E0B; /* Бурштиновий: заброньовано */

  /* 3. Адаптивна типографіка без медіа-запитів */
  --fs-hero: clamp(2rem, 5vw, 3.25rem); /* Масштабується плавно від 32px до 52px */
  --target-size: 44px;            /* WCAG 2.5.5 тач-таргет для пальця */
}

🚗 Статичний фон Hero: як поєднати графіку та читабельність

У нашій роботі автентичне зображення hero_bg.jpg (електромобіль біля ультрашвидкісної станції) задано як чистий бекграунд без створення додаткових тегів <img>. Для того, щоб текст зліва не зливався з авто, використано складений фон:

css/style.css — Hero background overlay 
.hero {
  background-color: var(--color-secondary);
  background-image: 
    linear-gradient(90deg, 
      rgba(15, 23, 42, 0.94) 0%,   /* Найтемніша зона зліва для контрасту тексту */
      rgba(15, 23, 42, 0.80) 45%,  /* М'який півтінь */
      rgba(15, 23, 42, 0.25) 100%  /* Прозорість справа: авто видно ідеально! */
    ),
    url('../assets/images/hero_bg.jpg');
  background-size: cover;
  background-position: center right;
  background-repeat: no-repeat;
}

Анатомія коду ChargeUA: Що за що відповідає

Детальний розбір структури index.html та допоміжних утиліт доступності.

🔗 .skip-link

Код: <a class="skip-link" href="#main">Перейти до основного вмісту</a>

Навіщо: Приховане посилання вгорі сторінки. Коли користувач натискає Tab на клавіатурі, воно спливає і дозволяє пропустити всі 15 посилань шапки і одразу перейти до <main id="main">.

WCAG 2.4.1 Bypass Blocks

👁️ .visually-hidden

Код: clip: rect(0 0 0 0); clip-path: inset(50%); height: 1px; width: 1px; overflow: hidden;

Навіщо: Приховує текст візуально з екрану, але зберігає його в Accessibility Tree для скрінрідера. Використано для уточнення контексту кнопок: «Прокласти маршрут до станції Київ ТРЦ».

WCAG 2.4.4 Link Purpose

🎯 :focus-visible

Код: :focus-visible { outline: 3px solid var(--color-primary); outline-offset: 2px; }

Навіщо: Показує контрастну рамку фокусу ТІЛЬКИ при переміщенні клавіатурою (Tab). Користувачі з мишкою не бачать синіх рамок при кліку, що зберігає естетику інтерфейсу.

20 Контрольних запитань викладача з еталонними відповідями

Найпопулярніші запитання доц. Юрчак І. Ю. та викладачів САПР під час захисту Лабораторної роботи №5.

Коротка відповідь

Семантичні теги несуть смислове навантаження про тип контенту для пошукових роботів та скрінрідерів, тоді як <div> є беззмістовним візуальним блоком.

Поглиблене пояснення

Кожен семантичний тег HTML5 автоматично транслюється браузером у відповідний вузол Accessibility Tree з ролями WAI-ARIA Landmark (наприклад: <header> → banner, <nav> → navigation, <main> → main, <footer> → contentinfo). Це дозволяє пошуковим системам краще індексувати важливий вміст, а людям з обмеженими можливостями — швидко переміщатися між розділами сайту за допомогою гарячих клавіш скрінрідера.

Коротка відповідь

Тег <h1> позначає єдину глобальну тему всього документа. Наявність кількох h1 розмиває фокус SEO-індексації та дезорієнтує незрячих користувачів.

Поглиблене пояснення

Згідно зі стандартами консорціуму W3C та алгоритмами ранжування Google, сторінка має деревоподібну ієрархію: h1 — заголовок першого рівня (книга / стаття), h2 — розділи (секції сайту), h3 — підрозділи або окремі картки послуг. У нашому проєкті ChargeUA єдиний <h1> розташовано в Hero-секції: «Швидка та надійна зарядка електромобілів по всій Україні».

Коротка відповідь

<article> — це повністю самостійний блок контенту, який не втрачає сенсу при вилученні зі сторінки. <section> — це тематичний розділ, тісно пов'язаний із контекстом усього документа.

Приклад у ChargeUA

Розділ каталогу станцій — це <section id="stations"> з власним заголовком h2. А кожна окрема картка зарядної станції (з адресою, потужністю DC 150 кВт та кнопкою бронювання) — це <article class="card">, бо її можна синдикувати у мобільний додаток чи RSS окремо від сайту.

Коротка відповідь

Посилання <a> (з обов'язковим атрибутом href) служить виключно для навігації (переходу між сторінками або до якоря). Кнопка <button> служить для виконання дії без зміни URL.

Поглиблене пояснення

Скрінрідери озвучують ці елементи по-різному: посилання як «link», а кнопку як «button». Клавіша Enter активує посилання, тоді як кнопку можна натиснути і Enter, і Space (пробілом). Якщо зробити перехід через <button onclick="location.href"> або дію через <a href="#"> — це грубе порушення доступності WCAG 4.1.2.

Поглиблене пояснення

Під час парсингу HTML-коду браузерний рушій паралельно створює дві структури: графічний DOM (Document Object Model) та Accessibility Tree. Дерево доступності транслює візуальні елементи в набір доступних об'єктів для операційної системи (UI Automation у Windows, NSAccessibility в macOS). Кожен об'єкт отримує 4 характеристики: Role (кнопка, орієнтир, список), Name (підпис з тексту або aria-label), State (фокус, checked, expanded) та Value.

Коротка відповідь

<aside> позначає другорядний (дотичний) контент, який доповнює основний, але може бути вилучений без втрати головного сенсу сторінки.

Приклад у ChargeUA

У блоці інтерактивної карти станцій тег <aside class="map-filters" aria-label="Фільтри пошуку станцій"> містить панель швидких перемикачів (потужність, конектор Type 2 / CCS 2, статус зайнятості). Він не є самою картою, а доповнює її інтерфейс.

Поглиблене пояснення

Псевдоклас :root відповідає кореню документа (елементу <html>), але має специфічність псевдокласу (0-1-0 проти 0-0-1 у звичайного тегу html). Усі змінні, оголошені з префіксом --ім'я: значення, автоматично наслідуються (каскадуються) всіма дочірніми вузлами. Змінні можна перевизначати локально всередині окремих класів (наприклад, .hero { --color-text: #FFFFFF; }), що робить архітектуру надзвичайно гнучкою.

Коротка відповідь

Щоб код залишався масштабованим, підтримував редизайн та зміну кольорових тем (Light / Dark) без абсурдних перейменувань.

Поглиблене пояснення

Якщо назвати змінну --blue: #005EC9, а через півроку бренд оновить колір на смарагдовий, вам доведеться або писати безглуздий код --blue: #10B981, або змінювати селектори по всьому CSS. Якщо ж назвати --color-primary — ви змінюєте лише одне значення в :root, і весь сайт миттєво підхоплює оновлення.

Коротка відповідь

Flexbox є одновимірним (1D — або рядок, або стовпчик), а CSS Grid є повноцінним двовимірним (2D — керує рядками і стовпчиками одночасно).

Поглиблене пояснення

Flexbox ідеальний для вирівнювання контенту відносно одного вектора: центрування іконки в кнопці, розстановка елементів шапки по краях (space-between), вирівнювання пунктів меню. CSS Grid призначений для каркасного проєктування площини: сітка каталогу товарів/станцій, дашборди, де елементи повинні суворо вирівнюватися по обох осях.

Поглиблене пояснення

Це найвідоміша формула сучасної адаптивної верстки:
1. minmax(280px, 1fr) задає діапазон розміру комірки: мінімум 280 пікселів (щоб картка не стискалася в тонку смужку), максимум 1fr (одна частка вільного простору).
2. auto-fit автоматично вираховує, скільки таких 280-піксельних колонок вміщується в поточну ширину екрана. Якщо місця вистачає на 3 колонки — створюється 3, якщо на 1 — створюється одна.
3. Усі створені колонки пропорційно розтягуються (1fr), повністю заповнюючи ширину батьківського контейнера без потреби писати 10 медіа-запитів.

Коротка відповідь

Поведінкою при нестачі елементів: auto-fit згортає порожні треки та розтягує наявні картки на весь простір, а auto-fill залишає порожні «фантомні» колонки праворуч.

Поглиблене пояснення

Функція clamp() реалізує математичне обмеження величини в діапазоні між нижньою та верхньою межею:
--fs-hero: clamp(2rem, 5vw, 3.25rem);
• На маленьких смартфонах розмір ніколи не впаде нижче 2rem (32px).
• На планшетах розмір розраховується динамічно як 5% від ширини екрана (5vw).
• На широкоформатних 4K моніторах розмір не роздується вище 3.25rem (52px). Це забезпечує ідеальну чуйність тексту без жодного @media!

Коротка відповідь

Це якірне посилання на початку документа, що веде на #main. Воно відповідає обов'язковому критерію WCAG 2.4.1 (Bypass Blocks).

Поглиблене пояснення

Користувачі, які рухаються сайтом за допомогою клавіатури або скрінрідера, без skip-link змушені щоразу на кожній сторінці натискати клавішу Tab 15–20 разів, щоб просто пройти крізь логотип, телефон та пункти меню. Skip-link дає можливість першим натисканням Tab перейти одразу до суті сторінки.

Стандартний CSS-патерн 
.visually-hidden {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border: 0;
}
Чому не display: none?

Властивість display: none повністю вилучає елемент із рендер-дерева та Accessibility Tree. Екранний диктор його проігнорує. А патерн .visually-hidden стискає розмір до 1 пікселя за межами екрану, тому диктор його прочитає, а звичайний користувач не побачить.

Поглиблене пояснення

Критерій WCAG 1.4.3 Contrast (Minimum) вимагає:
• Для звичайного тексту (до 18pt / 24px) мінімальний коефіцієнт контрасту між кольором тексту та фону має бути не менше 4.5 : 1.
• Для великого тексту (від 18pt або жирного 14pt) — не менше 3.0 : 1.
Перевірка здійснюється за допомогою інструменту Chrome DevTools (піпетка у вкладці Styles показує Contrast Ratio) або автоматичного аудиту Lighthouse.

Коротка відповідь

:focus-visible активує обведення ТІЛЬКИ тоді, коли користувач взаємодіє з клавіатури (Tab/стрілки), і НЕ показує обведення при кліку мишкою.

Поглиблене пояснення

Раніше розробники часто писали outline: none на :focus, бо їм не подобалась синя рамка при кліку мишкою. Але це повністю ламало доступність для людей з вадами зору. Псевдоклас :focus-visible є ідеальним компромісом: він зберігає красивий вигляд при роботі мишкою і гарантує чітку контрастну рамку для клавіатурного фокусу.

Коротка відповідь

Для оптимізації швидкості завантаження шрифтів (Core Web Vitals / LCP).

Поглиблене пояснення

Атрибут rel="preconnect" дає вказівку браузеру заздалегідь встановити TCP-з'єднання та виконати TLS-рукостискання з доменами fonts.googleapis.com та fonts.gstatic.com ще до того, як парсер дійде до самого CSS-файлу. Це економить 100–300 мс часу рендерингу тексту.

Коротка відповідь

Метою роботи є опанування фундаментальних механізмів специфікації CSS3 (Flexbox, CSS Grid, каскадність :root), а не використання готових чужих абстракцій.

Поглиблене пояснення

Фреймворки генерують сотні кілобайт надлишкових класів, які студент не контролює. Чистий CSS демонструє глибоке розуміння блочної моделі, відсутність конфліктів специфічності та 100% відповідність власноруч розробленій у ЛР №4 дизайн-системі ChargeUA.

Коротка відповідь

Це індикація того, що локальний сервер Live Server успішно піднято і він транслює сайт за адресою http://127.0.0.1:5500.

Поглиблене пояснення

У розширенні ritwickdey.liveserver кнопка у правому нижньому кутку має два стани:
1. ((•)) Go Live — сервер зупинений. Клік по ній запускає трансляцію.
2. ⊘ Port : 5500 — сервер активний. Клік по ній зупиняє (dispose) сервер.
Альтернативний запуск: правою кнопкою на index.html → «Open with Live Server» або комбінація Alt + L, Alt + O.

Поглиблене пояснення

Ідеальний результат 100 / 100 було забезпечено комплексом заходів:
• Повна семантична розмітка HTML5 (наявність усіх орієнтирів Landmark: banner, navigation, main, contentinfo).
• Додавання <a class="skip-link" href="#main"> для обходу блоків навігації.
• Кольоровий контраст тексту значно вищий за поріг 4.5:1 (для білого тексту на фоні #0F172A контраст складає понад 14:1).
• Усі зображення мають змістовні атрибути alt.
• Доступний стан фокусу з клавіатури :focus-visible на всіх посиланнях та кнопках.
• Дублювання колірних статусів текстовими бейджами та піктограмами.

Шпаргалка термінів та гарячих клавіш

Швидкий довідник ключових понять та абревіатур вебтехнологій.

W3C

World Wide Web Consortium — головна міжнародна організація, що розробляє та затверджує стандарти для Інтернету (HTML, CSS, SVG, WCAG).

WCAG 2.2

Web Content Accessibility Guidelines — офіційне керівництво з доступності вебконтенту. Рівень AA є міжнародним стандартом якості для державних та комерційних сервісів.

a11y

Числовий акронім від слова Accessibility (перша літера A, 11 проміжних літер, остання y). Означає проєктування вебсайтів, зручних для всіх людей, включно з особами з інвалідністю.

Landmark Roles

Семантичні орієнтири вебсторінки (banner, main, navigation, contentinfo, search), які дозволяють скрінрідерам миттєво стрибати між глобальними секціями.
