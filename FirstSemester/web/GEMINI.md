# Інструкції та правила проєкту (Project Rules)

## MCP-інструменти (Model Context Protocol)

- **`sequential-thinking`** — покрокове логічне мислення та аналіз.
- **`chrome-devtools-mcp`** — керування, тестування, інспектування DOM/CSS та аудит доступності (WCAG / Lighthouse) через Chrome DevTools.
- **`figma-dev-mode-mcp-server` / `figma-desktop` / `figma-developer-mcp`** — пряма взаємодія з Figma, читання/запис на полотно, робота з компонентами та дизайн-токенами.
- **`StitchMCP`** — ШІ-генерація екранів, варіантів інтерфейсу та дизайн-систем.
- **`mobbin`** — доступ до бібліотеки UI-шаблонів, реальних референсів та користувацьких сценаріїв (user flows).
- **`miro`** — створення та візуалізація дощок, карт сайту (sitemap), схем шляхів користувача (user flows) та прототипів.
- **`relume`** — підключення до бібліотеки UI-компонентів Relume для побудови інформаційної архітектури та каркасів.
- **`parallel-search`** — глибинний пошук та веб-дослідження.

## Спеціальні правила активації

- **`*` (Зірочка)** — введення зірочки дозволяє агенту автоматично використовувати будь-які доступні MCP-інструменти без ручного блокування та додаткових запитів на підтвердження.
