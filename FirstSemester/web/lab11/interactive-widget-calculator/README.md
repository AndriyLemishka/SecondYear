# Лабораторна робота №11: Розробка інтерактивних віджетів та обробка Edge Cases
## Інтерактивний калькулятор зарядки ChargeUA

Цей проєкт містить завершену інженерну реалізацію складного клієнтського віджета для розрахунку вартості та тривалості заряджання електромобілів відповідно до вимог **Лабораторної роботи №11**.

### Реалізований функціонал:
1. **Каталог електромобілів (ієрархія Auto.ria)**:
   - Понад 45 моделей електромобілів, згрупованих за виробниками (Tesla, Volkswagen, Nissan, Hyundai, Kia, BMW, Audi, Mercedes, BYD, Zeekr тощо) з використанням `<optgroup>`.
   - Швидкі пресети найпопулярніших авто в Україні: VW ID.4, Tesla Model 3, Nissan Leaf, Hyundai Ioniq 5.
   - Автоматичне підтягування ємності батареї (кВт·год) та сумісних стандартів портів.
2. **Гнучкий ручний режим (Custom Input)**:
   - Кнопка «Ввести ємність вручну», що плавно відкриває числове поле введення для нестандартних батарей чи кастомних конверсій.
3. **Двоспрямований діапазон заряду (Interactive Slider)**:
   - Інтерактивний діапазон заряду (поточний % $\to$ цільовий %).
   - Миттєвий перерахунок необхідної енергії, вартості за тарифом хабу, орієнтовного часу заряджання та доданого запасу ходу (км).
4. **Обробка граничних станів (Edge Cases)**:
   - Перевірка, щоб цільовий відсоток заряду не міг бути меншим або рівним поточному відсотку.
   - Захист від введення від'ємних значень ємності або екстремальних чисел ($>250$ кВт·год).
   - Обробка нульової потужності станції із захистом від ділення на нуль (`Division by Zero`).
   - Підтримка сенсорного введення на мобільних пристроях.
