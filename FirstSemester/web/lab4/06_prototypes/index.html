Як зарядитися за 3 прості кроки

Зрозумілий алгоритм для тих, хто заряджається вперше

1

Знайдіть станцію

Оберіть станцію на мапі ChargeUA за роз'ємом вашого авто (CCS2, Type 2 чи GB/T) та перевірте позначку генератора.

2

Підключіть порт

Вставте конектор у зарядний роз'єм автомобіля до клацання автоматичного замка блокування.

3

Слідкуйте за сесією

Контролюйте поповнення кіловат-годин у реальному часі та продовжуйте поїздку без зайвого хвилювання.

Відповіді на головні запитання українських водіїв електромобілів

Чи гарантовано працює станція під час відключень електроенергії?
Так, станції з позначкою «🔋 З генератором» мають автономне резервне живлення, що вмикається автоматично при знеструмленні міської електромережі.
Чи стягує ChargeUA додаткову комісію за пошук?
Ні, ChargeUA є 100% безкоштовним агрегатором. Ви оплачуєте вартість за кВт·год виключно за прямим тарифом обраної мережі.
Як підібрати перехідник для електромобіля з Китаю (GB/T) чи США (Type 1)?
