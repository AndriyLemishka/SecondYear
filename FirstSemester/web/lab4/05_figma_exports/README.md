# Інструкція з імпорту та створення проєкту ChargeUA у Figma

Ця папка містить готові файли для створення проєкту в Figma у відповідності до структури Лабораторної роботи №4 (фрейми `00_Cover` → `08_UX_Audit`).

---

## 🚀 Спосіб 1: Через локальний плагін Figma (Рекомендований та найпростіший)

1. Відкрийте **Figma Desktop** (або [figma.com](https://figma.com) у браузері).
2. Створіть новий чистий файл дизайну (**New Design File**).
3. У верхньому меню Figma оберіть:
   * **Menu (Логотип Figma)** → **Plugins** → **Development** → **Import plugin from manifest...**
4. У вікні, що з'явиться, оберіть файл:
   `d:\Studing\SecondYear\FirstSemester\web\lab4\05_figma_exports\manifest.json`
5. Натисніть правою кнопкою миші на полотні Figma:
   * **Plugins** → **Development** → **ChargeUA Figma Project Builder**.
6. **Готово!** За 2 секунди скрипт створить усі 9 обов'язкових фреймів:
   * `📁 00_Cover` (Титульна обкладинка з вашим іменем)
   * `📁 01_User_Flow` (3 критичні сценарії взаємодії)
   * `📁 02_Sitemap` (Карта сайту)
   * `📁 03_Wireframes` (Каркас)
   * `📁 04_Design_System` (Палітра токенів, кнопка у 6 станах, картки, відступи)
   * `📁 05_Desktop` (Повний макет 1440px)
   * `📁 06_Mobile` (Адаптивний макет 390px)
   * `📁 07_Prototype` (Зв'язки переходів)
   * `📁 08_UX_Audit` (Звіт аудиту доступності WCAG 2.2 AA)

---

## ⚡ Спосіб 2: Через консоль розробника Figma (Миттєво)

1. Відкрийте новий файл у Figma.
2. Натисніть гарячі клавіші:
   * У додатку Figma Desktop: `Ctrl + Shift + I`
   * У браузері: `F12` (або `Ctrl + Shift + J`), перейдіть на вкладку **Console**.
3. Відкрийте файл [`figma_builder_plugin.js`](file:///d:/Studing/SecondYear/FirstSemester/web/lab4/05_figma_exports/figma_builder_plugin.js), скопіюйте весь текст та вставте у консоль.
4. Натисніть `Enter`. Усі фрейми та компоненти з'являться на вашому полотні!

---

## 🔗 Як отримати посилання для звіту:
Після виконання скрипта у правому верхньому кутку Figma:
1. Натисніть синю кнопку **Share**.
2. Встановіть доступ: **"Anyone with the link can view"**.
3. Натисніть **Copy link**.
4. Вставте це посилання у звіт (Розділ «Посилання на Figma-проєкт»).
