## 2. Специфікація компонента «Кнопка» (Button/Primary) — Етап 10

Головний компонент кнопки заклику до дії (Primary CTA) спроєктовано зі строгим збереженням геометричних розмірів у всіх станах, щоб запобігти стрибкам контенту (Layout Shift).

### Базові параметри Main Component:
- **Висота (Height)**: фіксована `48 px`.
- **Внутрішні відступи (Padding)**: `top: 12px`, `bottom: 12px`, `left: 24px`, `right: 24px`.
- **Типографіка**: `Inter 14px`, `SemiBold (600)`, `Line-height: 20px`.
- **Радіус заокруглення (Border Radius)**: `8 px` (Medium).
- **Колір тексту та іконки**: `#FFFFFF` (чистий білий).
- **Auto Layout**: `Horizontal`, `Alignment: Center`, `Gap: 8px` між іконкою та текстом.

### Матриця варіантів (Variants):

| Стан (State) | Візуальні параметри (Фон, Обводка, Тінь) | Користувацький відгук (Feedback) | Коефіцієнт контрасту |
|---|---|---|:---:|
| **1. Default** | Фон: `#005EC9`, Обводка: немає, Тінь: `Shadow Sm` | Спокійний базовий вигляд. Заклик до дії домінує на сторінці. | **6.10:1 (AA)** |
| **2. Hover** | Фон: `#004BB5` (темніший на 15%), Тінь: `Shadow Md` | Відгук наведення курсору. Відчуття готовності до кліку. | **7.85:1 (AAA)** |
| **3. Pressed / Active** | Фон: `#003A8F` (темніший на 30%), Тінь: немає, Масштаб: `transform: scale(0.98)` | Тактильний ефект фізичного натискання клавіші. | **10.12:1 (AAA)** |
| **4. Focus** | Фон: `#005EC9`, Фокусне кільце: `3px solid #005EC9`, `offset: 2px #FFFFFF` | Чітка вказівка поточної позиції при табі з клавіатури (WCAG SC 2.4.7). | **6.10:1 (AA)** |
| **5. Disabled** | Фон: `#E2E8F0`, Текст: `#94A3B8`, Курсор: `not-allowed`, Події: `pointer-events: none` | Однозначне блокування дії (наприклад, якщо не обрано авто). | **3.0:1** (Норматив для неактивних) |
| **6. Loading** | Фон: `#005EC9`, Текст: прихований / напівпрозорий, Центр: обертовий SVG-спінер `#FFFFFF` | Інформування про обчислення маршруту без зміни ширини кнопки. | **6.10:1 (AA)** |

## 3. Специфікація компонентів карток (Cards) — Етап 11

### 1. Картка станції (`Card/Station`):
- **Складники**:
  * Заголовок станції (`Inter 16px Bold`) + адреса (`13px Muted`).
  * Бейдж автономності: `🔋 Працює від генератора` (Зелений фон `#D1FAE5`, текст `#047857`).
  * Список портів з іконками: `⚡ CCS2 (120 кВт) — Вільний`, `⚡ Type 2 (22 кВт) — Вільний`.
  * Тариф за 1 кВт·год: великі цифри `14.50 ₴/кВт·год`.
  * Дія: Кнопка «Прокласти маршрут» (висота 40px).

### 2. Картка тарифу оператора (`Card/Tariff`):
- **Складники**:
  * Логотип мережі (EcoFactor, Yasno, TOKA, GO TO-U).
  * Бейдж ціни (наприклад: `🔥 Найкраща ціна`).
  * Акцентна вартість DC: `14.50 ₴` (Display 28px).
  * Тариф AC: `10.99 ₴` (Small 12px).
  * Кнопка дії: `Показати станції на карті`.

### 3. Картка кроку інструкції (`Card/Step`):
- **Складники**:
  * Нумерація у синьому круглому бейджі (діаметр 36px, білий текст 1-2-3).
  * Заголовок кроку (`Inter 18px Bold`).
  * Пояснювальний текст (`Inter 14px Secondary`).
