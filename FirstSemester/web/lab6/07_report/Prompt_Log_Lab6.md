## 1. Промпт для аналізу офіційних вимог кафедри
> **Промпт:**  
> "Проаналізуй офіційну сторінку дисципліни https://www.victoria.lviv.ua/library/students/wd/work6.html. Виділи обов'язкові етапи лабораторної роботи №6 (Google Maps, Google Street View, YouTube, Vimeo, HTML5 Audio, інформери погоди, курсу валют і годинника, соціальні плагіни) та сформулюй відповіді на всі 10 контрольних запитань за 3-компонентною моделлю: коротка відповідь, академічне обґрунтування, практичний зразок коду для проєкту ChargeUA."

## 2. Промпт для безпечного та продуктивного вбудовування iFrame карт
> **Промпт:**  
> "Згенеруй семантичну структуру адаптивного контейнера для Google Maps з географічними координатами кафедри САПР Львівської політехніки (вул. С. Бандери, 12). Обов'язково застосуй атрибути безпеки та оптимізації продуктивності: loading='lazy', allowfullscreen='', referrerpolicy='no-referrer-when-downgrade'. Забезпеч стилізацію картки зі статусом швидкісних портів."

## 3. Промпт для порівняльного аналізу відеосервісів YouTube та Vimeo
> **Промпт:**  
> "Реалізуй порівняльну 2-колонкову CSS Grid секцію для демонстрації відео з YouTube та Vimeo. Для YouTube використай безпечний хостинг youtube-nocookie.com з параметрами rel=0 та modestbranding=1. Для Vimeo забезпеч чистий інтерфейс без реклами. Забезпеч адаптивність контейнерів через сучасне CSS-правило aspect-ratio: 16/9 без застосування застарілих padding-bottom хаків."

## 4. Промпт для нативного HTML5 Audio
> **Промпт:**  
> "Створи семантичний блок аудіосупроводу з елементом <audio controls preload='metadata'>. Реалізуй резервування джерел за стандартом: перший пріоритет — оптимізований MP3 (320 kbps), другий — безстиснений WAV (PCM 16-bit). Оформи блок у картку голосового асистента ChargeUA з інформацією про бітрейт і тривалість."

## 5. Промпт для динамічних інформерів та соціальних кнопок
> **Промпт:**  
> "Створи адаптивну сітку віджетів: 
> 1) Метеорологічний інформер Sinoptik.ua (температура у Львові та вплив на батарею EV); 
> 2) Таблиця курсів валют НБУ (USD, EUR, PLN) для міжнародних розрахунків; 
> 3) Годинник точного часу Time.is з підсвічуванням дії нічного пільгового тарифу; 
> 4) Кнопки швидкого поширення через відкриті Intent URL соцмереж (Telegram, Facebook, Instagram кафедри САПР) без встановлення сторонніх трекінгових скриптів."

## 6. Промпт для генерації ДСТУ-звіту
> **Промпт:**  
> "Склади академічний звіт до Лабораторної роботи №6 з титульною сторінкою НУ 'Львівська політехніка', гербом, вступом, покроковим описом 9 етапів роботи, 9 реальними скріншотами високої чіткості, анатомією коду, вичерпними відповідями на всі 10 контрольних запитань та 5 висновками. Експортуй у формати DOCX та векторний PDF."
