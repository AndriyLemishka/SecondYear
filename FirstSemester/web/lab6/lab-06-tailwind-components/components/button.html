Етап 5 ЛР №6

Primary CTA Button «Дізнатися більше»

Ізольований компонент кнопки згідно WCAG 2.2 AA (min-h: 44px, стани hover, active, disabled, focus-visible).

1. Стандартний стан (Default & Interactive)

2. Стан відключення (Disabled state)

3. Ghost-кнопка вторинної дії (Secondary / Ghost)

Пояснення використаних утиліт:

  • min-h-[44px] — відповідність WCAG 2.5.5/2.5.8 (Touch Target Minimum).
  • bg-blue-600 hover:bg-blue-700 — інтерактивна зміна фону при наведенні.
  • active:scale-95 — тактильний зворотний зв'язок при натисканні (micro-interaction).
  • focus-visible:ring-4 focus-visible:ring-blue-300 — чіткий контур фокусу для доступності з клавіатури без появи небажаних рамок при кліку мишкою.
  • transition-all duration-200 ease-in-out — апаратне анімування змін стилю.
