## Структура чистого проєкту:
- `index.html` — головна сторінка проєкту ChargeUA зі семантичною розміткою HTML5 та інтегрованими компонентами Tailwind CSS.
- `css/`
  - `style.css` — власні CSS токени (:root), стилі шапки, підвалу, геро-секції та адаптивних сіток.
  - `tailwind.min.css` — скомпільовані utility-класи Tailwind CSS.
- `js/`
  - `nav.js` — модуль доступного гамбургер-меню (WCAG 2.2).
  - `calculator.js` — інтерактивний калькулятор зарядки з базою 45+ моделей авто та ручним введенням ємності.
  - `stations-filter.js` — фільтрація карток станцій за містами, наявністю вільних конекторів та пошуком.
  - `map.js` — інтерактивна карта Leaflet із точками зарядних хабів по Україні (lazy loading).
- `assets/` — SVG-іконки, логотипи, оптимізовані зображення (WebP) та геодані станцій.
- `netlify.toml` — конфігурація заголовків кешування та вимкнення сторонніх тулбарів.
