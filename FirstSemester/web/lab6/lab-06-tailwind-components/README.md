# Лабораторна робота №6: Мобільна адаптивність та компонентна верстка
## Адаптивна мобільна версія ChargeUA (Mobile-First & Hamburger Menu)

Ця версія містить повну реалізацію адаптивного дизайну під мобільні пристрої (320px–768px), планшети та десктопи відповідно до завдань **Лабораторної роботи №6**.

### Що реалізовано:
1. **Адаптивна шапка з гамбургер-меню (Етап 6 ЛР №6)**:
   - Кнопка гамбургер-меню (`.burger-btn`) для мобільних екранів (< 1160px).
   - Мобільне висувне меню (Drawer `.nav.is-open`) з затемненням та блокуванням скролу сторінки.
   - Скрипт керування станом (`js/nav.js`): перемикання `aria-expanded`, закриття клавішею Escape, закриття при кліку поза межами меню.
2. **Принцип Mobile-First та медіа-запити (Етап 7 та Етап 15)**:
   - Оптимізовані розміри кнопок (мінімум 44×44px для сенсорного натискання пальцем).
   - Горизонтальний скрол тач-чипів фільтрів на мобільних пристроях.
   - Одноколонкова сітка карток на мобільних (`grid-template-columns: 1fr`) з переходом у 2 колонки на планшетах та 3 на десктопах.
3. **Готовність до міграції на Tailwind CSS (Етапи 8–14)**:
   - Усі класи та розмітки готові до прямої заміни на утиліти Tailwind (`md:hidden`, `hidden md:flex`, `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`).
