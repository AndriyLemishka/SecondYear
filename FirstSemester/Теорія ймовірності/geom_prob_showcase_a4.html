ТЕМА 4: ГЕОМЕТРІЯ
1. Трикутник у колі (Варіант 12) Планіметрія
Умова: Точка круга радіуса $R$ попаде у вписаний трикутник $ABC$ ($AB = 2R, AC = CB = R\sqrt{2}$).

• $AB = 2R$ — діаметр кола $\implies \angle C = 90^\circ$ (вписаний кут, що спирається на діаметр).

• За теоремою Піфагора: $AC^2 + CB^2 = 2R^2 + 2R^2 = 4R^2 = AB^2$.

• Повна площа: $S(D) = S_{\text{круг}} = \pi R^2$.

• Сприятлива площа: $S(d) = \frac{1}{2} AC \cdot CB = \frac{1}{2} (R\sqrt{2})^2 = R^2$.

• Геометрична ймовірність: $P = \frac{S(d)}{S(D)} = \frac{R^2}{\pi R^2} = \frac{1}{\pi}$.

Відповідь: $P = \frac{1}{\pi} \approx 0{,}3183 \ (31{,}83\%)$
2. Класична «Задача про зустріч» Різниця координат
Умова: Двоє приходять між 12:00 та 13:00. Перший чекає 15 хв ($1/4$ год) і йде. Ймовірність зустрічі?

• Час приходу $x, y \in [0; 1]$. Квадрат $D = [0; 1]^2$, $S(D) = 1$.

• Умова зустрічі: $|x - y| \le \frac{1}{4} \iff x - \frac{1}{4} \le y \le x + \frac{1}{4}$.

• Два порожні кутові трикутники (розминулися):

$$S_{\text{не}} = 2 \cdot \left(\frac{1}{2} \cdot \frac{3}{4} \cdot \frac{3}{4}\right) = \left(\frac{3}{4}\right)^2 = \frac{9}{16}$$

• Сприятлива площа смуги: $S(d) = 1 - \frac{9}{16} = \frac{7}{16}$.

Відповідь: $P = \frac{7}{16} = 0{,}4375 \ (43{,}75\%)$
3. Дійсні корені рівняння (Варіант 8) Парабола / Інтеграл
Умова: $x^2 + px + q = 0$, де $p, q \in [-1; 1]$. Знайти ймовірність, що корені дійсні й різні.

• $D = [-1; 1] \times [-1; 1] \implies S(D) = 2 \cdot 2 = 4$.

• Дійсні різні корені $\iff D_{\text{дискр}} = p^2 - 4q > 0 \iff q < \frac{p^2}{4}$.

• Інтегруємо висоту від нижньої межі $q = -1$ до параболи:

$$S(d) = \int_{-1}^1 \left(\frac{p^2}{4} - (-1)\right) dp = 2 \left[\frac{p^3}{12} + p\right]_0^1 = 2 \cdot \frac{13}{12} = \frac{13}{6}$$

• $P = \frac{S(d)}{S(D)} = \frac{13/6}{4} = \frac{13}{24} \approx 0{,}5417$.

Відповідь: $P = \frac{13}{24} \approx 0{,}5417 \ (54{,}17\%)$
4. Гіпербола в квадраті (Варіант 11) Гіпербола / Інтеграл
Умова: $M(x, y)$ у квадраті $[0; 1]^2$. Знайти ймовірність $xy < a$, де $0 < a < 1$.

• Повна область: $D = [0; 1]^2 \implies S(D) = 1$.

• Умова $xy < a \iff y < \frac{a}{x}$. Розбиваємо область на дві:

1. $x \in [0; a]$: $\frac{a}{x} \ge 1 \implies$ прямокутник $S_1 = a \cdot 1 = a$.

2. $x \in [a; 1]$: $S_2 = \int_a^1 \frac{a}{x} dx = a \ln x \big|_a^1 = -a \ln a$.

• $S(d) = S_1 + S_2 = a - a \ln a = a(1 - \ln a)$.

Відповідь: $P = a(1 - \ln a)$
5. Зламана паличка (Трикутник) Нерівність трикутника
Умова: Паличку навмання ламають у 2 точках. Знайти ймовірність, що з 3 частин можна скласти трикутник.

• Нехай точки зламу $0 < x < y < L$. Довжини 3 частин: $x$, $y - x$, $L - y$.

• Умова трикутника: кожна частина менша за суму двох інших (тобто менша за $L/2$):

$$x < L/2, \quad y - x < L/2, \quad y > L/2$$

• Сприятлива область — це центральний трикутник площею $\frac{1}{4}$ від площі повного трикутника наслідків.

Відповідь: $P = \frac{1}{4} = 0{,}25 \ (25\%)$
6. Метод рамки / Гомотетія (Варіант 10) Вкладені фігури
Умова: У квадраті $10 \times 10$ см навмання взято точку. Відстань до найближчої сторони $\le 2$ см.

• Повний квадрат: сторона $a = 10$ см, площа $S(D) = 10^2 = 100$ см².

• Точки на відстані $> 2$ см від усіх сторін утворюють внутрішній концентричний квадрат:

$$a_{\text{внутр}} = 10 - 2 \cdot 2 = 6\text{ см} \implies S_{\text{внутр}} = 6^2 = 36\text{ см}^2$$

• Площа сприятливої рамки: $S(d) = 100 - 36 = 64$ см².

• $P = \frac{S(d)}{S(D)} = \frac{64}{100} = 0{,}64$.

Відповідь: $P = 0{,}64 \ (64\%)$
