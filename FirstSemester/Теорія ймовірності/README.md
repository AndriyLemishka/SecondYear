# Теорія ймовірностей та математична статистика (2 курс, 1 семестр)

## Про проект
Дана папка містить методичні та розрахункові матеріали з дисципліни **«Теорія ймовірностей, ймовірнісні процеси та математична статистика»** (НУ «Львівська політехніка», кафедра обчислювальної математики і програмування).

**Студент:** Лемішка Андрій (група ПП-24)  
**Індивідуальний варіант РГР:** **Варіант № 11**
