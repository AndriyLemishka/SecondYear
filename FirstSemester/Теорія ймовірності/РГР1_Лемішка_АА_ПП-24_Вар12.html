1. Скількома способами можна впорядкувати множину {1, 2, ..., n} так, щоб числа 1, 2, 3 стояли поруч і в порядку зростання?
Об'єднаємо числа 1, 2, 3 в один неподільний блок X = (1, 2, 3). Порядок чисел усередині блоку фіксований (1 спосіб).
Кількість елементів для перестановки: (n − 3) вільних чисел плюс 1 блок X, разом N = n − 2 елементи.
Число способів впорядкування: Pn−2 = (n − 2)!
Відповідь: N = (n − 2)!
2. Гральна кістка кидається один раз. Результат експерименту — число очок на верхній грані: Ω = {1, 2, 3, 4, 5, 6}.
Події: M — випало ≥ 3; N — випало < 4; K — випало парне число.
Підмножини: M = {3, 4, 5, 6},   N = {1, 2, 3},   K = {2, 4, 6}.
Перевірка на сумісність:
M ∩ N = {3} ≠ ∅;   M ∩ K = {4, 6} ≠ ∅;   N ∩ K = {2} ≠ ∅ ⇒ всі пари сумісні.
Опис подій:
M ∩ N = {3}
M ∩ K = {4, 6}
N ∩ K = {2}
M ∪ N = {1, 2, 3, 4, 5, 6} = Ω — достовірна подія.
N̄ = {4, 5, 6} — випало не менше 4 очок.
M ∪ N ∪ K = Ω — достовірна подія.
M ∩ N ∩ K = {3} ∩ {2, 4, 6} = ∅ — неможлива подія.
K̄ = {1, 3, 5} — випало непарне число.
Відповідь: усі три події попарно сумісні; M ∪ N = Ω, M ∩ N ∩ K = ∅.
3. Студент знає 40 з 60 питань програми. У білеті 5 питань. Знайти ймовірність того, що студент складе іспит, якщо для цього треба відповісти принаймні на 4 питання з білета.
Загальна кількість питань N = 60. Знає: K = 40; не знає: 60 − 40 = 20. У білеті n = 5.
Загальне число варіантів: nзаг = C605 = 5 461 512.

а) Рівно 4 відомих і 1 невідоме: m1 = C404 · C201 = 91 390 · 20 = 1 827 800.
б) Усі 5 відомих: m2 = C405 · C200 = 658 008 · 1 = 658 008.
Сприятливі випадки: m = 1 827 800 + 658 008 = 2 485 808.
P(A) = 2 485 808/5 461 512 ≈ 0,4551.
Відповідь: P(A) ≈ 0,4551   (45,51%).
4. Точка навмання кидається в круг радіуса R. Знайти ймовірність того, що вона потрапить у вписаний трикутник ABC, якщо AB = 2R, а AC = CB = R√2.
Оскільки сторона AB = 2R є діаметром кола, вписаний ΔABC спирається на діаметр ⇒ ∠C = 90° (прямокутний трикутник).
Площа прямокутного рівнобедреного трикутника: Sd = 1/2 · (R√2) · (R√2) = R2.
Площа всього круга: SD = πR2.
За формулою геометричної ймовірності:
P = Sd/SD = R2/πR2 = 1/π ≈ 0,3183.
Відповідь: P = 1/π ≈ 0,3183.

5. Мандрівник виходить з пункту A і на кожному роздоріжжі вибирає навмання один із можливих шляхів. Знайти ймовірність того, що він дістанеться пункту B.
З пункту A виходять 4 рівноймовірні гілки першого кроку: P(Hi) = 1/4 (i = 1, 2, 3, 4).
Умовні ймовірності потрапити в B з кожної гілки:
• Гілка 1: роздоріжжя на 4 шляхи (3 в тупик, 1 в B) ⇒ P(B | H1) = 1/4.
• Гілка 2: веде прямо в тупик ⇒ P(B | H2) = 0.
• Гілка 3: веде безпосередньо в пункт B ⇒ P(B | H3) = 1.
• Гілка 4: вузол з 3 шляхами (1 в B з ймов. 1/3, 1 в тупик 1/3, 1 у вузол V5 де 2 виходи з ймов. 1/2 до B) ⇒ P(B | H4) = 1/3 + 1/3 · 1/2 = 1/2.
За формулою повної ймовірності:
P(B) = ∑ P(Hi) · P(B | Hi) = 1/4 · 1/4 + 1/4 · 0 + 1/4 · 1 + 1/4 · 1/2 = 1/16 + 0 + 4/16 + 2/16 = 7/16 = 0,4375.
Відповідь: P(B) = 7/16 = 0,4375   (43,75%).

8. Ймовірність бракованої деталі p = 0,09. Знайти ймовірність того, що серед 180 відібраних деталей бракованих буде не менше 15 і не більше 30, якщо випробування незалежні.

np = 180 · 0,09 = 16,2;
√npq = √(180 · 0,09 · 0,91) = √14,742 ≈ 3,84.

P180(15 ≤ k ≤ 30) ≈ Φ0(x2) − Φ0(x1), де

10. Щільність випадкової величини ξ задається формулою f(x) = (4 − x)/8 при x ∈ (0; 4) і f(x) = 0 при x ∉ (0; 4). Знайти F(x), P(ξ ∈ [2; 3]), моду, медіану, Mξ, Dξ.

2) P(2 ≤ ξ ≤ 3) = F(3) − F(2) = (3/2 − 9/16) − (1 − 4/16) = 15/16 − 12/16 = 3/16 = 0,1875.
3) Мода: f(x) спадна на [0; 4], максимум у точці 0 ⇒ Mo = 0.
