ВАРІАНТ 12
Завдання 1 Комбінаторика
Умова: Скількома способами можна впорядкувати множину {1, 2, ..., n} так, щоб числа 1, 2, 3 стояли поруч і в порядку зростання?

• Метод «блоку»: числа 1, 2, 3 утворюють єдиний блок $X = (1, 2, 3)$.

• Порядок всередині $X$ фіксований: лише $1$ спосіб.

• Кількість елементів: $(n - 3)$ чисел + $1$ блок $X = (n - 2)$ об'єкти.

• Кількість перестановок: $N = P_{n-2} = (n-2)!$

Відповідь: $N = (n - 2)!$
Завдання 2 Алгебра подій
Умова: Гральну кістку підкидають 1 раз. $M$: число $\ge 3$; $N$: $< 4$; $K$: парне. Сумісність та опис операцій.

• $\Omega = \{1,2,3,4,5,6\}$. $M=\{3,4,5,6\}, N=\{1,2,3\}, K=\{2,4,6\}$.

• $M \cap N = \{3\} \neq \varnothing$; $M \cap K = \{4, 6\} \neq \varnothing$; $N \cap K = \{2\} \neq \varnothing$ (усі пари сумісні).

• $M \cap N = \{3\}$, $M \cup N = \Omega$, $N \cap K = \{2\}$.

• $\bar{N} = \{4, 5, 6\}$, $\bar{K} = \{1, 3, 5\}$, $N \setminus K = \{1, 3\}$.

• $M \cap N \cap K = \varnothing$ (неможлива), $M \cup N \cup K = \Omega$ (достовірна).

Відповідь: Усі пари сумісні
Завдання 3 Класична ймовірність
Умова: Студент знає 40 з 60 питань. Іспит: відповісти принаймні на 4 з 5 у білеті. Яка ймовірність скласти?

• $N = 60, K = 40, N-K = 20, n = 5$.

• $n_{\text{заг}} = C_{60}^5 = 5\,461\,512$.

• «Принаймні 4 з 5»: рівно 4 або всі 5 відомих:

$$m_1 = C_{40}^4 C_{20}^1 = 91\,390 \cdot 20 = 1\,827\,800$$

$$m_2 = C_{40}^5 C_{20}^0 = 658\,008 \cdot 1 = 658\,008$$

$$P = \frac{1\,827\,800 + 658\,008}{5\,461\,512} = \frac{2\,485\,808}{5\,461\,512} \approx 0{,}4551$$

Відповідь: $P \approx 0{,}4551 \ (45{,}51\%)$
Завдання 4 Геометрична ймовірність
Умова: Точка круга радіуса $R$ попаде у вписаний трикутник $ABC$ ($AB = 2R, AC = CB = R\sqrt{2}$).

• $AB = 2R$ — діаметр $\implies \angle C = 90^\circ$ (прямокутний $\triangle$).

• $S_D = \pi R^2$; $S_d = \frac{1}{2} (R\sqrt{2})^2 = R^2$.

• $P = \frac{S_d}{S_D} = \frac{R^2}{\pi R^2} = \frac{1}{\pi} \approx 0{,}3183$.

Відповідь: $P = \frac{1}{\pi} \approx 0{,}3183$
Завдання 5 Повна ймовірність
Умова: Мандрівник виходить з $A$, на кожному роздоріжжі вибирає напрям навмання (не повертаючись). Ймовірність потрапити в $B$?

• З $A$ є рівноможливі напрями розгалуження.

• За формулою повної ймовірності підсумовуються ймовірності всіх допустимих шляхів від $A$ до $B$:

$$P(B) = \sum_{\text{ланцюжки}} P(\text{шлях}_{A \to B})$$

Результат: $P(B)$ через суму шляхів
Завдання 6 Схема Бернуллі
Умова: Кубик: що ймовірніше — з 5 кидків $\le 2$ разів парне, чи з 7 кидків $\ge 3$ разів парне?

• $p = q = 0{,}5$ (парне очко: $2, 4, 6$).

• 1 випадок ($n=5, k \le 2$):

$$P_5(k \le 2) = \frac{C_5^0 + C_5^1 + C_5^2}{2^5} = \frac{16}{32} = 0{,}5000$$

• 2 випадок ($n=7, k \ge 3$):

$$P_7(k \ge 3) = 1 - \frac{C_7^0 + C_7^1 + C_7^2}{2^7} = 1 - \frac{29}{128} = \frac{99}{128} \approx 0{,}7734$$

• $0{,}7734 > 0{,}5000$.

Відповідь: З 7 кидків $\ge 3$ ($77{,}34\%$)
Завдання 7 Дискретна ВВ
Умова: ВВ $\xi$ має 2 значення: $x_1 < x_2$, $p_1 = 0{,}3$, $M\xi = 3{,}2$, $D\xi = 0{,}15$. Знайти ряд розподілу.

• $p_2 = 1 - 0{,}3 = 0{,}7$.

• $M\xi = 0{,}3 x_1 + 0{,}7 x_2 = 3{,}2$.

• $D\xi = p_1 p_2 (x_2 - x_1)^2 = 0{,}21 (x_2 - x_1)^2 = 0{,}15$.

• $(x_2 - x_1)^2 = \frac{0{,}15}{0{,}21} = \frac{5}{7} \implies x_2 - x_1 = \sqrt{5/7} \approx 0{,}845$.

• $x_1 = 3{,}2 - 0{,}7 \sqrt{5/7} \approx 2{,}608$; $x_2 = 3{,}2 + 0{,}3 \sqrt{5/7} \approx 3{,}454$.

Ряд розподілу: $x_1 \approx 2{,}61; \ x_2 \approx 3{,}45$
Завдання 8 Муавр-Лаплас
Умова: 9% телевізорів з браком. Яка ймовірність, що серед 180 телевізорів від 15 до 30 бракованих?

• $n = 180, p = 0{,}09, q = 0{,}91$.

• $np = 16{,}2$, $\sqrt{npq} = \sqrt{180 \cdot 0{,}09 \cdot 0{,}91} \approx 3{,}84$.

• Інтегральна теорема: $P(15 \le k \le 30) \approx \Phi_0(x_2) - \Phi_0(x_1)$.

$$x_1 = \frac{15 - 16{,}2}{3{,}84} = -0{,}31; \quad x_2 = \frac{30 - 16{,}2}{3{,}84} = 3{,}59$$

$$P \approx \Phi_0(3{,}59) + \Phi_0(0{,}31) = 0{,}4998 + 0{,}1217 = 0{,}6215$$

Відповідь: $P \approx 0{,}6215 \ (62{,}15\%)$
Завдання 9 Ряд і многокутник ВВ
Умова: З урни (7 білих, 3 чорні) виймають 2. $\xi$ — число білих. Побудувати многокутник, знайти $M, D, \sigma$.

• $\xi \in \{0, 1, 2\}$. $C_{10}^2 = 45$.

• $p_0 = \frac{C_3^2}{45} = \frac{1}{15}$; $p_1 = \frac{C_7^1 C_3^1}{45} = \frac{7}{15}$; $p_2 = \frac{C_7^2}{45} = \frac{7}{15}$.

• $M\xi = 1{,}4$; $D\xi = \frac{7}{3} - 1{,}4^2 \approx 0{,}373$; $\sigma \approx 0{,}611$.

Числові хар-ки: $M = 1{,}4; D = 0{,}37; \sigma = 0{,}61$
Завдання 10 Неперервна ВВ
Умова: $f(x) = \frac{4-x}{8}$ на $(0; 4)$. Знайти $F(x), P(x \in [2; 3]), Mo, Me, M\xi, D\xi$.

• $F(x) = \frac{x}{2} - \frac{x^2}{16}$; $P(2 \le x \le 3) = F(3) - F(2) = \frac{3}{16} = 0{,}1875$.

• $Mo = 0$; $Me = 4 - 2\sqrt{2} \approx 1{,}172$.

• $M\xi = \int_0^4 x \frac{4-x}{8} dx = \frac{4}{3}$; $D\xi = \frac{8}{9} \approx 0{,}889$.

Параметри: $P = \frac{3}{16}; M = \frac{4}{3}; D = \frac{8}{9}$
Завдання 11 Функція від ВВ
Умова: $f(x) = A(x^2 + 2x)$ на $(0; 1)$. Знайти $A$, $M\eta, D\eta$ для $\eta = 2\xi$.

• Нормування: $\int_0^1 A(x^2 + 2x) dx = A \frac{4}{3} = 1 \implies A = \frac{3}{4}$.

• $M\xi = \frac{3}{4} \int_0^1 (x^3 + 2x^2) dx = \frac{11}{16} = 0{,}6875$.

• $M\eta = M(2\xi) = 2 M\xi = \frac{11}{8} = 1{,}375$.

• $M\xi^2 = \frac{3}{4} \int_0^1 (x^4 + 2x^3) dx = \frac{21}{40} = 0{,}525$.

• $D\xi = \frac{21}{40} - (\frac{11}{16})^2 \approx 0{,}05234 \implies D\eta = 4 D\xi \approx 0{,}2094$.

Відповідь: $A = \frac{3}{4}; M\eta = 1{,}375; D\eta \approx 0{,}209$
Завдання 12 Характеристична ф-я
Умова: Знайти характеристичну функцію для $f(x) = 3x^2$ на $[0; 1]$. За нею знайти $M\xi$ та $D\xi$.

• $\varphi_\xi(t) = \int_0^1 e^{itx} 3x^2 dx$.

• Інтегруванням частинами:

$$\varphi_\xi(t) = \frac{3}{it} e^{it} + \frac{6}{(it)^2} e^{it} - \frac{6}{(it)^3} (e^{it} - 1)$$

• $M\xi = \frac{1}{i} \varphi'(0) = \int_0^1 3x^3 dx = \frac{3}{4} = 0{,}75$.

• $M\xi^2 = -\varphi''(0) = \int_0^1 3x^4 dx = \frac{3}{5} = 0{,}6$.

• $D\xi = M\xi^2 - (M\xi)^2 = \frac{3}{5} - \frac{9}{16} = \frac{3}{80} = 0{,}0375$.

Відповідь: $M\xi = \frac{3}{4}; \ D\xi = \frac{3}{80} = 0{,}0375$
