Теорія ймовірностей — Формуляр A4 (Сторінка 1: Теми 1–8)

НУ «Львівська політехніка» • Повний рукописний масштаб із назвами та поясненнями формул

Аркуш 1 • Лицьовий бік
1. Елементи комбінаторики Тема 1
Правило суми (АБО): $N = m + k$ • Правило добутку (І): $N = m \cdot k$
Без повторень: Перестановки $P_n = n!$; Розміщення $A_n^m = \frac{n!}{(n-m)!}$; Сполучення $C_n^m = \frac{n!}{m!(n-m)!}$
З повтореннями: $$\bar{A}_n^m = n^m, \qquad \bar{C}_n^m = C_{n+m-1}^m = \frac{(n+m-1)!}{m!(n-1)!}, \qquad \bar{P}_n(k_1,\dots,k_r) = \frac{n!}{k_1!\dots k_r!}$$
Біном Ньютона: $(a+b)^n = \sum_{k=0}^n C_n^k a^{n-k}b^k$, загальний член $T_{k+1} = C_n^k a^{n-k}b^k$
Властивості $C_n^k$: $C_n^k = C_n^{n-k}, \quad C_{n+1}^k = C_n^k + C_n^{k-1}, \quad \sum_{k=0}^n C_n^k = 2^n, \quad \sum (-1)^k C_n^k = 0$
Розбиття на $k$ однакових груп по $m$ ($N=km$): $W = \frac{N!}{(m!)^k k!}$ • По колу: $P = (n-1)!$
Формула Стірлінга: $n! \approx \sqrt{2\pi n}\left(\frac{n}{e}\right)^n$
2. Простір подій та аксіоматика Колмогорова Тема 2
Події: вірогідна $\Omega$ ($P=1$), неможлива $\varnothing$ ($P=0$), протилежна $\bar{A} = \Omega \setminus A \implies P(\bar{A}) = 1 - P(A)$
Операції над подіями: $A \cup B$ (сума), $AB$ (добуток), $A \setminus B = A\bar{B}$ (різниця)
Симетрична різниця: $A \Delta B = (A \setminus B) \cup (B \setminus A)$
Закони де Моргана: $$\overline{A \cup B} = \bar{A} \cap \bar{B}, \qquad \overline{A \cap B} = \bar{A} \cup \bar{B}$$
Аксіоми Колмогорова: 1) $P(A) \ge 0$; 2) $P(\Omega)=1$; 3) $P(\bigcup_{i=1}^\infty A_i) = \sum P(A_i)$ для несумісних.
Повна група подій: $\bigcup_{i=1}^n A_i = \Omega, \; A_i A_j = \varnothing \implies \sum_{i=1}^n P(A_i) = 1$
Властивість монотонності: $A \subset B \implies P(A) \le P(B), \quad P(B \setminus A) = P(B) - P(AB)$
3. Означення ймовірності (Класичне, Геометричне) Тема 3
Класичне означення: $P(A) = \frac{m}{n} = \frac{|A|}{|\Omega|}$ ($0 \le P(A) \le 1$) • Частота: $W_n(A) = \frac{m}{n} \xrightarrow{P} P(A)$
Гіпергеометрична схема ($N$ предметів, $K$ мічених, вибірка $n$ без повернення): $$P(X = k) = \frac{C_K^k \cdot C_{N-K}^{n-k}}{C_N^n}, \quad M[X] = n\frac{K}{N}, \quad D[X] = n\frac{K}{N}\left(1-\frac{K}{N}\right)\frac{N-n}{N-1}$$
Геометрична ймовірність: $P(A) = \frac{\operatorname{mes}(d)}{\operatorname{mes}(D)}$ (1D: довжини $l/L$, 2D: площі $S/S_0$, 3D: об'єми $V/V_0$)
Задача про зустріч ($|x-y| \le \tau \le T$): $P = \frac{T^2 - (T-\tau)^2}{T^2} = \frac{2\tau}{T} - \left(\frac{\tau}{T}\right)^2$
Задача Бюффона (голка довжиною $2l$ на смуги кроком $2a$): $P = \frac{2l}{\pi a}$
4. Теореми додавання та множення ймовірностей Тема 4
Теорема додавання: $P(A \cup B) = P(A) + P(B) - P(AB)$ (для несумісних $AB=\varnothing \implies P(A)+P(B)$)
Формула включення-виключення: $P(A\cup B\cup C) = \sum P(A) - \sum P(AB) + P(ABC)$
Умовна ймовірність та теорема множення: $$P(A \mid B) = \frac{P(AB)}{P(B)} \iff P(AB) = P(B)P(A \mid B) = P(A)P(B \mid A)$$
Ланцюгове правило для $n$ подій: $P(A_1 \dots A_n) = P(A_1)P(A_2|A_1)P(A_3|A_1 A_2)\dots P(A_n|A_1\dots A_{n-1})$
Незалежні події: $P(AB) = P(A)P(B) \iff P(A \mid B) = P(A)$
Настання хоча б однієї події: $P(\ge 1) = 1 - q_1 q_2 \dots q_n$ • Рівно одна подія: $p_1 q_2 q_3 + q_1 p_2 q_3 + q_1 q_2 p_3$
5. Повна ймовірність та формули Байєса Тема 5
Повна група гіпотез: $\bigcup_{i=1}^n H_i = \Omega, \; H_i H_j = \varnothing, \; \sum_{i=1}^n P(H_i) = 1$
Формула повної ймовірності (апріорний прогноз наслідку $A$): $$P(A) = \sum_{i=1}^n P(H_i) \cdot P(A \mid H_i)$$
Формула Байєса (апостеріорна переоцінка гіпотези $H_k$ за фактом $A$): $$P(H_k \mid A) = \frac{P(H_k) \cdot P(A \mid H_k)}{\sum_{j=1}^n P(H_j) \cdot P(A \mid H_j)} = \frac{P(H_k \cap A)}{P(A)}$$
$P(H_k)$ — апріорна (дослідна) ймовірність; $P(H_k|A)$ — уточнена апостеріорна після події $A$.
6. Схема незалежних випробувань Бернуллі Тема 6
$n$ незалежних однорідних дослідів, $P(\text{успіх}) = p, \quad q = 1 - p$.
Формула Бернуллі (рівно $k$ успіхів у $n$ дослідах): $$P_n(k) = C_n^k \, p^k \, q^{n-k} = \frac{n!}{k!(n-k)!} p^k q^{n-k}$$
Найімовірніше число успіхів $k_0$: $np - q \le k_0 \le np + p$
Якщо $np-q$ дробове $\implies k_0 = [np+p]$; якщо ціле $\implies$ два значення: $np-q$ та $np+p$.
Мультиноміальна схема: $P_n(k_1,\dots,k_r) = \frac{n!}{k_1!\dots k_r!} p_1^{k_1} \dots p_r^{k_r}, \quad \sum k_i = n$
Геометричний розподіл (до 1-го успіху): $P(X = k) = q^{k-1}p, \quad M[X]=\frac{1}{p}, \quad D[X]=\frac{q}{p^2}$
7. Граничні теореми схеми Бернуллі Тема 7
Локальна теорема Муавра-Лапласа ($npq \ge 10$): $$P_n(k) \approx \frac{1}{\sqrt{npq}} \, \varphi(x), \quad x = \frac{k - np}{\sqrt{npq}}, \quad \varphi(x) = \frac{e^{-x^2/2}}{\sqrt{2\pi}}$$ Властивість: $\varphi(-x) = \varphi(x)$ (парна функція Гаусса).
Інтегральна теорема Муавра-Лапласа ($k_1 \le k \le k_2$): $$P_n(k_1 \le k \le k_2) \approx \Phi_0(x_2) - \Phi_0(x_1), \quad \Phi_0(x) = \frac{1}{\sqrt{2\pi}} \int_0^x e^{-t^2/2} dt, \quad x = \frac{k - np}{\sqrt{npq}}$$ $\Phi_0(-x) = -\Phi_0(x), \; \Phi_0(\infty) = 0.5$. Поправка: $x_1 = \frac{k_1 - 0.5 - np}{\sqrt{npq}}, \; x_2 = \frac{k_2 + 0.5 - np}{\sqrt{npq}}$.
Відхилення відносної частоти: $P\left(\left|\frac{k}{n} - p\right| \le \varepsilon\right) \approx 2\Phi_0\left(\varepsilon \sqrt{\frac{n}{pq}}\right), \quad n \ge \frac{u_\gamma^2 pq}{\varepsilon^2}$
Теорема Пуассона ($n \to \infty, p \to 0, \lambda = np \le 10$): $$P_n(k) \approx \frac{\lambda^k}{k!} e^{-\lambda}, \qquad \text{оцінка похибки: } \sum_{k=0}^\infty |P_n(k) - \Pi_k| \le 2np^2$$
8. Дискретні випадкові величини (ДВВ) Тема 8
Ряд розподілу: $\{(x_i, p_i)\}, \; \sum p_i = 1$ • Функція розподілу: $F(x) = P(X < x) = \sum_{x_i < x} p_i$
Матсподівання та Дисперсія: $$M[X] = \sum_i x_i p_i, \quad D[X] = \sum_i x_i^2 p_i - (M[X])^2, \quad \sigma_X = \sqrt{D[X]}$$
Властивості $M$ і $D$: $M[C]=C, \; M[CX]=CM[X], \; M[X+Y]=M[X]+M[Y]$
$D[C]=0, \; D[CX]=C^2 D[X], \; D[X+C]=D[X]$
Для незалежних: $M[XY]=M[X]M[Y], \quad D[X \pm Y] = D[X] + D[Y]$
Для залежних: $D[X \pm Y] = D[X] + D[Y] \pm 2\operatorname{cov}(X,Y)$
Моменти: $\mu_1 = 0, \; \mu_2 = D[X], \; \mu_3 = \alpha_3 - 3\alpha_1\alpha_2 + 2\alpha_1^3, \; \alpha_k = \sum x_i^k p_i$
