1. Теореми додавання та множення Фундамент

Операція «АБО» (Додавання ймовірностей):

• Несумісні (A ∩ B = ∅):   P(A ∪ B) = P(A) + P(B)
• Сумісні (довільні):   P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Операція «І» (Множення та умовна ймовірність):

Ймовірність події B за умови, що A відбулася: P(B | A) = P(A ∩ B) / P(A).

• Залежні події:   P(A ∩ B) = P(A) · P(B | A)
• Незалежні події:   P(A ∩ B) = P(A) · P(B)
2. Повна ймовірність та формула Байєса Гіпотези

Нехай H1, H2, …, Hn — повна група несумісних гіпотез (∑ P(Hi) = 1):

Формула повної ймовірності:
P(A) = ∑i=1n P(Hi) · P(A | Hi)

Формула Байєса (переоцінка апріорної ймовірності):

Якщо подія A вже сталася, нова ймовірність гіпотези Hk:

P(Hk | A) = [ P(Hk) · P(A | Hk) ] / P(A)
★ Завдання 5 (Твій Варіант 12): Мандрівник на роздоріжжі з графом шляхів Варіант 12 • РГР

Умова: Мандрівник виходить з пункту A і на кожному роздоріжжі вибирає навмання одне з можливих продовжень шляху (не повертаючись назад). Яка ймовірність того, що він потрапить у пункт B?

Аналіз розгалужень та ймовірностей шляхів:

• З пункту A виходять 4 рівноможливі дороги: P(H1) = P(H2) = P(H3) = P(H4) = 1/4.
• З V1 виходить 4 стежки (3 тупики, 1 веде в B):   P(B | H1) = 1/4.
• З V2 виходить лише 1 тупикова стежка:   P(B | H2) = 0.
• З V3 виходить 1 пряма стежка до B:   P(B | H3) = 1.
• З V4 є 3 варіанти: прямо в B (1/3), тупик (1/3), у вузол V5 (1/3 · 1/2 до B):
  P(B | H4) = 1/3 · 1 + 1/3 · 0 + 1/3 · (1/2) = 1/3 + 1/6 = 1/2.

Застосування формули повної ймовірності:

P(B) = (1/4 · 1/4) + (1/4 · 0) + (1/4 · 1) + (1/4 · 1/2) = 1/16 + 0 + 4/16 + 2/16 = 7/16
Відповідь для Варіанта 12: P(B) = 7/16 = 0,4375 (43,75%)
Варіант 1: Формула Байєса (Урни) Апостеріорна ймов.

Умова: Є 3 урни. Склад кульок (білі/чорні):
У1: (2 б, 1 ч), У2: (3 б, 1 ч), У3: (2 б, 2 ч). Навмання витягнуто білу кульку (подія A). Знайти ймовірність, що її взято з У1.

P(H1) = P(H2) = P(H3) = 1/3
P(A|H1) = 2/3;   P(A|H2) = 3/4;   P(A|H3) = 2/4 = 1/2
Повна ймов. P(A):
1/3 · (2/3 + 3/4 + 1/2) = 1/3 · 23/12 = 23/36

Переоцінка за Байєсом:

P(H1 | A) = [ (1/3 · 2/3) ] / (23/36) = 8/23 ≈ 0,3478
Відповідь: P(H₁|A) = 8/23 (34,78%)
Варіант 13: Метод протилежної події «Хоча б одне»

Умова: Проводяться 3 незалежні постріли. Ймовірності влучання: p1 = 0,6; p2 = 0,7; p3 = 0,8. Знайти ймовірність хоча б одного влучання.

Ймовірності промахів (протилежні події):
q1 = 1 − 0,6 = 0,4
q2 = 1 − 0,7 = 0,3
q3 = 1 − 0,8 = 0,2
Ймовірність жодного влучання (Ā):
P(Ā) = q1 · q2 · q3 = 0,4 · 0,3 · 0,2 = 0,024

Шукана ймовірність:

P(A) = 1 − P(Ā) = 1 − 0,024 = 0,976
Відповідь: P(A) = 0,976 (97,6%)
Варіант 5: Заводи та % браку Виробництво

Умова: Завод 1 випускає 60% продукції (брак 2%), Завод 2 — 40% (брак 4%). Виріб виявився бракованим. Яка ймовірність, що він з Заводу 2?

P(H1) = 0,60;   P(Брак|H1) = 0,02
P(H2) = 0,40;   P(Брак|H2) = 0,04
Загальний брак P(Б):
0,60 · 0,02 + 0,40 · 0,04 = 0,012 + 0,016 = 0,028

Ймовірність того, що брак з Заводу 2:

P(H2 | Б) = 0,016 / 0,028 = 16/28 = 4/7 ≈ 0,5714
Відповідь: P(H₂|Б) = 4/7 (57,14%)
