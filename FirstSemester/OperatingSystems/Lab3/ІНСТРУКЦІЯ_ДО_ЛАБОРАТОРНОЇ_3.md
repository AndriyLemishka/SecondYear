# Покрокова інструкція для виконання Лабораторної роботи №3 в Ubuntu (WSL)

Ця шпаргалка створена для того, щоб ви могли легко повторити всі команди з методички самостійно у терміналі Ubuntu.

---

## 🚀 Як відкрити термінал Ubuntu
* **Спосіб 1 (Найпростіший):** На вашому **Робочому столі (Desktop)** двічі клікніть на новий ярлик **«Ubuntu Terminal»**.
* **Спосіб 2:** Запустіть **«Термінал» (Windows Terminal)**, зверху натисніть на стрілочку `v` поруч із плюсиком і виберіть **Ubuntu**.
* **Спосіб 3:** Відкрийте **PowerShell** і просто введіть `wsl` та натисніть Enter.

Після запуску у вас відкриється рядок:
```bash
user@ubuntu:~$ 
```

## 📌 Блок 1. Навігація, файли та права доступу (Завдання 1)

Виконуйте команди по черзі (копіюйте рядок і натискайте Enter):

```bash
# 1. Створити каталоги mydir1 та mydir2
mkdir mydir1 mydir2

# 2. Перейти в mydir1
cd mydir1

# 3. Створити файл file1.txt і наповнити його текстом
cat << 'EOF' > file1.txt
Plaintext
Turn on the machine.
Start the program.
Request the option.
End the program.
Turn off the machine.
EOF

# 4. Зробити копії file2.txt та file3.txt
cp file1.txt file2.txt
cp file1.txt file3.txt

# 5. Дописати рядок у file2.txt
echo "It is new string1." >> file2.txt

# 6. Дописати рядки у file3.txt
echo "It is new string 2. It is new string 3." >> file3.txt

# 7. Перемістити файли file2.txt та file3.txt у каталог mydir2
mv file2.txt file3.txt ../mydir2/

# 8. Вивести вміст file1.txt
cat file1.txt

# 9. Перевірити права доступу
ls -l file1.txt

# 10. Додати права на виконання власнику (u+x) та групі (g+x)
chmod u+x,g+x file1.txt
ls -l file1.txt

# 11. Скопіювати file1.txt у домашній каталог
cp file1.txt /home/user

# 12. Перейменувати локальний файл на file.txt
mv file1.txt file.txt

# 13. Видалити file.txt
rm file.txt

# 14. Повернутися в домашній каталог
cd ..

# 15. Знищити тепер порожній каталог mydir1
rmdir mydir1

# 16. Перейти в каталог mydir2 та подивитися файли
cd mydir2
ls -la

# 17. Порівняти файли через comm і зберегти у res.txt
comm file2.txt file3.txt > res.txt
cat res.txt

# 18. З'єднати файли file2.txt та file3.txt в один новий file.txt
cat file2.txt file3.txt > file.txt
cat file.txt

# 19. Повернутися в домашній каталог
cd ~

# 20. Записати повний список файлів у dir.txt
ls -l /home/user > dir.txt
cat dir.txt

# 21. Вивести календар на 2026 рік
cal 2026

# 22. Вивести останні 10 команд
history 10
```

## 📌 Блок 2. Керування процесами та моніторинг (Завдання 2)

```bash
# 1. Запустити цифровий годинник у фоні
xclock -digital &

# 2. Перевести його на передній план (foreground)
fg %1

# (Натисніть на клавіатурі Ctrl + Z, щоб призупинити його)

# Відновити його виконання у фоні:
bg %1

# 3. Запустити аналоговий годинник у фоні:
xclock &

# 4. Переглянути фонові задачі та процеси:
jobs -l
ps -u user -o pid,stat,time,command

# 5. Переглянути стан оперативної пам'яті:
free -h

# 6. Переглянути час роботи системи та навантаження (load average):
uptime
date

# 7. Запустити динамічний моніторинг процесів:
top
# (Щоб вийти з top, натисніть клавішу q на клавіатурі)
```

## 📌 Блок 3. Пошук, обробка тексту та архіви (Завдання 3)

```bash
# 1. Переглянути сторінки довідки (для виходу з man натискайте q)
man find
man grep
man tar

# Дізнатися, де лежать файли керівництв та бінарники:
man -w find grep tar
whereis -b -m find grep tar

# 2. Підрахувати кількість звичайних файлів у домашньому каталозі:
find /home/user -maxdepth 1 -type f | wc -l

# 3. Зберегти всі звичайні файли у filelist1.txt:
find /home/user -type f ! -type l > filelist1.txt
head -n 5 filelist1.txt

# 4. Знайти файли понад 5 КБ та зберегти атрибути у filelist2.txt:
# (створимо тестовий лог-файл 7 КБ, якщо його ще немає)
head -c 7168 /dev/urandom > /home/user/large_data.log
find /home/user -type f -size +5k | xargs ls -lh > filelist2.txt
cat filelist2.txt

# 5. Знайти файли зі словом bash:
locate bash | head -n 10

# 7. Відфільтрувати користувачів із домашніми каталогами у /home з номерами рядків:
grep -n "/home" passwd_example > filelist3.txt
cat filelist3.txt

# 8. Стиснути filelist1.txt утилітою gzip зі ступенем 1 та 9:
gzip -k -1 filelist1.txt && mv filelist1.txt.gz filelist1_fast.gz
gzip -k -9 filelist1.txt && mv filelist1.txt.gz filelist1_best.gz

# 9. Стиснути утилітою bzip2 зі ступенем 1 та 9:
bzip2 -k -1 filelist1.txt && mv filelist1.txt.bz2 filelist1_fast.bz2
bzip2 -k -9 filelist1.txt && mv filelist1.txt.bz2 filelist1_best.bz2

# 10. Порівняти розміри стиснутих файлів:
ls -lh filelist1*
gzip -l filelist1_best.gz

# 11. Створити архів tar з трьох файлів:
tar -cvf archive.tar filelist1.txt filelist2.txt filelist3.txt

# 12. Додати файл passwd_example у створений tar-архів:
tar -rvf archive.tar passwd_example

# 13. Створити zip-архів із 4 файлів:
zip archive.zip filelist1.txt filelist2.txt filelist3.txt passwd_example

# 14. Порівняти розміри отриманих архівів:
ls -lh archive.tar archive.zip

# 15. Розпакувати tar та zip архіви у окремі каталоги:
mkdir -p extracted_tar && tar -xvf archive.tar -C extracted_tar
mkdir -p extracted_zip && unzip archive.zip -d extracted_zip
ls -la extracted_tar extracted_zip
```
